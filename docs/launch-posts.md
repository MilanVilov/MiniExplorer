## Hacker News

**Title:** Show HN: MiniExplorer – a free Finder replacement that works like Windows Explorer

**URL:** https://github.com/MilanVilov/MiniExplorer

**First comment (post right after submitting):**

I've never gotten along with Finder, so I built the file manager I wanted: an address bar you can type a path into, tabs, a plain list or icon view, and built-in preview for images, PDFs and text. It also edits Markdown in place (inspired by DHH's OmaWriter).

It's a native SwiftUI app, free, no account, no telemetry. Mostly vibe coded, built for my own daily use, so expect rough edges. The release is Apple Silicon only and not notarized (right-click > Open the first time).

MIT licensed. I'd like to hear what Finder annoyances I should fix next.

**Title:** I got fed up with Finder and made a free Explorer-style alternative

**Body:**

MiniExplorer is a small, free file manager for macOS.

- Type-a-path address bar
- Tabs for folders and previews
- Built-in preview for images, PDFs and text, with no Quick Look pop-ups
- Markdown editing in place
- Clipboard history, a few themes

No premium tier, no account. It's vibe coded and built for my own use, so it has rough edges and I'd appreciate feedback. Apple Silicon, macOS 15+.
